# Security Policy

## Scope & Intended Deployment

Kopi is designed as a **single-station LAN appliance** for a trusted, isolated local network (e.g., home or small office Wi-Fi with client isolation/WPA2+). It is **not** designed for direct exposure to the public internet.

## Reporting a Vulnerability

If you discover a security vulnerability in Kopi, please report it privately via GitHub Security Advisories on this repository rather than opening a public issue.
